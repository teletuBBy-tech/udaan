# Contributing

- Keep Hindi labels simple, legible and respectful; preserve text fallbacks for voice-only interactions.
- Never add a real opportunity without a source URL, verification status and last-verified date.
- Do not invent fees, vacancies, eligibility rules, salaries or partner endorsements.
- Use synthetic student profiles in development and tests.
- Keep eligibility deterministic and explainable. An unknown rule must return `unable_to_determine`.
- Validate structured model outputs server-side and keep all secrets out of frontend assets.
- Add tests for changed business rules and document browser-dependent voice/map/offline behaviour.
- Keep touch targets large and keyboard focus visible.
